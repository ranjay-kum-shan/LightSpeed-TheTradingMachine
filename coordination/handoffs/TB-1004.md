## Completion Summary

The system now has one canonical UTC primitive and an injectable time boundary.
`ensure_utc` rejects every naive timestamp and normalizes aware ones to UTC.
`ExchangeSession` carries UTC bounds together with the exchange-local session
date, so session identity survives normalization. `Clock` and `ExchangeCalendar`
are declared in `domain` as ports, with `SystemClock`, a deterministic
`ManualClock`, and a `StaticExchangeCalendar` implementing them.

Evidence covers naive rejection, offset conversion, both US daylight-saving
transitions, ambiguous local time resolved by `fold`, half-open session
boundaries, a holiday, a half-day, and calendar validation.

Deliberately not included: real holiday and half-day calendar data with pinned
versions (TB-3003), and wiring session eligibility into `RiskEngine` or the
execution path (TB-5004). DATA-003 is fully served; EXEC-006 receives only its
session contract and boundary primitives.
