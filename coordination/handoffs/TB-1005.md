## Completion Summary

`src/trading_bot/audit/` now holds the structured event schema and the single
redaction boundary that every log line must pass through.

`AuditEvent` carries every field of the
[structured event contract](../../docs/08-operations-and-observability.md),
normalizes both timestamps through the TB-1004 `ensure_utc` primitive, refuses a
record time earlier than the occurrence time, and requires a stable dotted
lowercase `event_type`. Scope identity is enforced by mode: a `BACKTEST` event
requires `run_id`, and `PAPER` or `RECOVERY` events require `session_id`. AUD-001
is enforced structurally: an event whose type begins with `decision.` cannot be
constructed without `strategy_id`, `git_revision`, `config_hash`, `data_hash`,
`reason_code`, and a non-empty payload.

`Redactor` is the boundary. It masks registered canary literals anywhere,
secret-named keys at any nesting depth, URL userinfo, query and header pairs
whose name is credential-like, and authorization scheme values, including inside
multiline strings and nested arrays. It refuses anything it cannot classify:
arbitrary objects, exceptions, `datetime`, sets, binary values, and non-string
mapping keys all raise `RedactionFailure` rather than being stringified.
`serialize_event` renders one canonical JSON line and then rescans the rendered
line, raising if any known secret survived.

Residual safety or security risk: the guard is name-based and literal-based.
After cycle-one remediation a credential-named field masks its whole value up to
the next delimiter, which closes quoted values, JSON bodies, tab and URL-encoded
separators, and every authorization scheme. What remains uncovered is a secret
under a name the matcher does not recognize as credential-like. Concretely,
`?code=`, `?state=`, `?hash=`, `?id=`, `?client_id=`, and single-letter parameter
names are not caught, because each is a common legitimate parameter and flagging
them would destroy ordinary evidence. `session_id` is deliberately excluded
because it is a first-class field of the event contract, so a web session token
stored under that name would not be caught. Registering canaries with the
`Redactor` remains the only complete guarantee. Scanning is bounded: inputs over
64 KB are refused rather than scanned, so a large captured body cannot stall the
audit path. All test canaries are synthetic strings beginning with `canary-`; no
real credential format is embedded anywhere. No sink, file, or network path is
introduced, so nothing yet writes an event to disk.

### Review Cycle One Findings

The reviewer attacked the boundary with adversarial probes rather than reading
alone, and found that the schema half was sound while the pattern half of the
redactor failed on the most common real-world carriers. The reviewer's summary
judgement was that the output could carry the `[REDACTED]` marker beside an
intact credential, which is worse than no redaction because it defeats the manual
log review the security specification relies on.

| ID | Severity | Finding |
| --- | --- | --- |
| C1 | Critical | `_AUTH_SCHEME` recognized only four schemes. `Authorization: NTLM <secret>` rendered as `Authorization: [REDACTED] <secret>`; the scheme word was masked and the credential survived, for at least eight schemes |
| C2 | Critical | The pair pattern's value class excluded quote characters, so no quoted value was ever redacted: JSON bodies, `key="value"`, XML attributes, and Python `repr` output all passed through untouched |
| M1 | Major | `serialize_event` redacted only `event_id` and `account_fingerprint`; eight free-text identity fields were emitted raw |
| M2 | Major | Quadratic scan time; doubling input multiplied runtime by about 3.8, so a few hundred kilobytes would stall the audit path and, by the operations contract, the side effect it precedes |
| M3 | Major | A redacted-key collision silently dropped map entries from append-only evidence |
| M4 | Major | A `HALTED`-mode decision event could be constructed with neither `run_id` nor `session_id`, breaking AUD-001 exactly when traceability matters most |
| M5 | Major | The `decision.` prefix under-covered: the contract requires a reason code for decisions, rejections, transitions, and alerts, and only the first was enforced |
| M6 | Major | Confirmed behavioural divergence with the duplicated matcher in `data/models.py`: `cookie` is a fragment here and not there |
| M7 | Major | Homoglyph bypass: name normalization deleted non-ASCII characters, so a Cyrillic `аpi_key` normalized to `pikey` and passed |
| N1 to N6 | Minor | Uncontrolled `RecursionError` past depth 500; non-finite floats emitted as invalid JSON; false positives unrecorded; `NamedTuple` degraded to a positional list; the `config` dependency; `audit` absent from the architecture table |

The reviewer explicitly found no scope creep, no safety-boundary breach, no
schema-fidelity defect, and no test tautology, and killed all six of its own
planted mutations.
