## Completion Summary

The domain package now exposes contract version `1`, one canonical
machine-readable `ReasonCode` registry, fourteen recognized reason families,
canonical order purposes, and all twelve order lifecycle states required by the
execution specification. Configuration, risk, kill, and heartbeat producers now
return the canonical enum without changing their serialized string values.

The original `RiskReason` remains a distinct risk-only enum with the same member
names, iteration surface, accepted type, and serialized values. Its values are
sourced from `ReasonCode`; no broker, persistence, network, credential, or
live-trading behavior was added.
