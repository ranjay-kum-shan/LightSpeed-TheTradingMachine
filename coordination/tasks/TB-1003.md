## Objective

Create one versioned domain registry for stable machine-readable reason codes and
complete the canonical initial order-purpose and lifecycle values without
changing any existing serialized value.

## Scope

### In Scope

- Add a standard-library-only `ReasonCode` registry under `trading_bot.domain`.
- Preserve every currently emitted configuration, risk, kill, and heartbeat code.
- Add canonical order purpose and lifecycle status enums from the execution spec.
- Add a public contract version and compatibility tests.
- Prove current configuration, risk, and operations outputs parse through the
  registry without changing their serialized values.
- Migrate current configuration, risk, and operations producers to return the
  canonical enum while preserving string equality and `RiskReason` imports.

### Out of Scope

- Broker ports, adapters, state transitions, persistence, network calls, or SDKs.
- Renaming existing reason-code values.
- Live trading, real credentials, owner-dependent values, leverage, or shorting.
- Moving runtime/trading state or operating mode ownership in this task.
